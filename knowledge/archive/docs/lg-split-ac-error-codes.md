# Split AC error codes

LG's table maps dozens of codes to sensor (thermistor) faults, indoor/outdoor communication failures, compressor and inverter-board protections, fan motor locks and memory errors. LG notes that **not every model shares the same codes**, and the table is meant for describing the fault to an installer or technician.

Only one entry has a customer action: an indoor/outdoor **communication error** during normal use may be a temporary fault from unstable power — switch off at the breaker for about 5 minutes and restore power; if it repeats, a technician must check it. Low refrigerant (shown as code 38 on some units) always needs repair service.

**FixFirst policy:** AC codes are recorded (with the brand) and passed to the technician; the agent never explains or acts on them, because the same code means different things on different brands and models.
