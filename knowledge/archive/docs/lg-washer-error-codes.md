# LG washing machine error codes (top load and front load)

These notes summarise LG India's guidance in our own words. Always prefer the manual for the exact model.

## Codes a customer can act on
- **IE — water not filling.** Open the tap fully, look for a kinked inlet hose, clean the inlet filter. Often a household water-pressure issue rather than a machine fault.
- **OE — water not draining.** Clean the drain filter, straighten the drain hose, check for blockages (coins, hair, lint) before assuming the drain motor failed.
- **UE — unbalanced load.** Spread the laundry evenly; wash heavy items like blankets one at a time on the blanket cycle.
- **vS / uS — vibration sensor.** Level the machine, keep it off the wall, reduce the load.
- **dL — lid or door not locked.** Check for clothing caught in the latch and close firmly. Request service if it keeps happening.
- **CL — child lock on.** Hold the lock button for 3–5 seconds (varies by model).
- **tcL — tub clean reminder.** Not a fault; run the tub clean cycle.
- **PF — power failure.** Only records a power cut during a cycle; the cycle resumes.

## Codes that need a restart, then a technician
- **PE — water level sensor.** Unplug and restart; if it persists, a technician must visit.
- **FE — overfill.** Unplug, restart; if it returns, the water level sensor is likely faulty.
- **E3 — drain motor.** Reset the machine.
- **AE, tE** — mostly clear with a restart.
- If **the same code comes back twice in a row**, stop troubleshooting and call a technician.

## Manual reset
Unplug at the wall and close the tap, wait 1–5 minutes so the control board discharges, run Drain or Spin if water is left, then plug in and run Rinse + Spin before a normal wash.

## Other tips
The door usually unlocks a minute or two after a cycle. Machine won't start: check the socket and cord, and that the lid is fully closed. Start does nothing: child lock is usually on. Keep detergent doses correct; excess suds strain draining.
